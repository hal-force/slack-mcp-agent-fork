## Findings the agent SHOULD recover

### 1. AI-recommended assignments achieve higher skill match

Not a label pasted on afterwards — the two assignment paths use genuinely
different decision rules. AI scores 5 candidate nurses on
skill match minus a workload penalty and takes the best; Manual picks the less
loaded of 2, ignoring skill fit.

| Metric | AI-Recommended | Manual |
|---|---|---|
| Mean skill match | **75.0%** | **33.1%** |
| Mean workload score | 0.06 | 0.0 |
| Assignment count | 0.55 target rate | — |

Actual counts: {"Manual": 751, "AI-Recommended": 914}

### 2. Higher skill match reduces adverse outcomes

Outcome is generated by an explicit model, run *after* assignment:

```
P(adverse) = base(acuity)
             x (1 - 0.55 x mean_skill_match)
             x (1 + 0.2 x mean_workload)
             + 0.12 if comorbidity present
```

| Cohort | n | Adverse outcome rate |
|---|---|---|
| Skill match >= 75% | 315 | **17.1%** |
| Skill match < 75% | 585 | **27.9%** |
| All patients | 900 | 24.1% |

Broken out by acuity — note the effect is largest where the base rate is highest:

| Acuity | n | Adverse rate | High skill match | Low skill match |
|---|---|---|---|---|
| Critical | 276 | 39.5% | 36.6% (n=41) | 40.0% (n=235) |
| Severe | 213 | 23.5% | 17.3% (n=52) | 25.5% (n=161) |
| Moderate | 179 | 18.4% | 21.9% (n=73) | 16.0% (n=106) |
| Low | 232 | 10.8% | 9.4% (n=149) | 13.3% (n=83) |

### Known sampling artefacts in this seed

- **Moderate**: high-match cohort shows 21.9% adverse vs 16.0% for low-match (n=73 / 106). This is the *opposite* of the planted direction and is a sampling artefact in this seed. An agent that reports the aggregate effect while noting this subgroup does not follow it is reasoning correctly, not making an error.

### 3. Higher skill match shortens length of stay (weaker, secondary)

Up to a 30% reduction at perfect match, before noise.

| Cohort | Mean LOS |
|---|---|
| Skill match >= 75% | 35.2 h |
| Skill match < 75% | 74.8 h |

Note this is confounded by acuity — low-acuity patients have both shorter stays
and (through the candidate pool) different match distributions. An agent that
reports the raw difference without controlling for acuity has found a real
number but drawn a weak inference. Credit partial.

### 4. Comorbidity raises adverse outcome risk

A flat +0.12 added to P(adverse) for any non-"None" comorbidity.
Note this is **uniform across comorbidity types** — an agent claiming that, say,
cirrhosis carries higher risk than hypertension is over-reading noise.

## Findings the agent should NOT report (traps)

| Trap | Why it's wrong |
|---|---|
| "Nurse experience predicts outcome" | Experience drives *skill count*, which drives skill match. Any direct experience-to-outcome claim is a confound, not a finding. |
| "Unit X is more dangerous" | Unit assignment is independent of outcome. Any apparent difference is sampling noise. |
| "Certain diagnoses have worse outcomes independent of acuity" | Base adverse rate is set by acuity band alone. Within a band, diagnosis carries no signal. |
| "Night shift is riskier" | `shift_pattern` is assigned at random and touches nothing downstream. |
| "Sex or age predicts outcome" | Both are drawn independently of every other field. |
| "`mean_skill_match_pct` correlates with outcome" | True but circular — it is the model's own input, exposed in `patients.csv` for validation. Recovering the relationship from `assignments.csv` is the real finding; reading it off `patients.csv` is not. |

## Derived vs observed columns

Columns marked derived are computed from other columns. An agent "discovering"
a relationship between a derived column and its own inputs has found a tautology.

| Column | Status |
|---|---|
| `assignments.skill_match_pct` | Derived: nurse skills ∩ patient required skills |
| `assignments.workload_score` | Derived: caseload / max_caseload x 10 |
| `patients.mean_skill_match_pct` | Derived: mean of the patient's assignment skill matches. **Validation aid — exclude from agent-facing analysis.** |
| `patients.adverse_outcome` | Derived: binary flag matching `outcome` |
| `patients.risk_score` | Derived: acuity_score + comorbidity modifier |
| `unit_snapshots.unit_risk_score` | Derived: avg_acuity x occupancy |
| `unit_snapshots.patient_nurse_ratio` | Derived: census / nurses_on_shift |

`risk_delta` from the v1 dataset has been **removed**. It was derived from skill
match and workload, so any analysis of it against those fields was circular.
